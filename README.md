# japantrip

My Japan Trip app - Una aplicación interactiva para explorar viajes a Japón con información de lugares, hoteles, restaurantes, transportes y cronología.

## 🚀 Ejecución

### Requisitos previos
- Node.js 16+ 
- npm o yarn

### Instalación

```bash
npm install
```

### Desarrollo

Ejecutar el servidor de desarrollo en modo watch:

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`

### Build (Producción)

Compilar la aplicación para producción:

```bash
npm run build
```

Los archivos compilados se generarán en la carpeta `dist/`

### Vista previa de la build

Previsualizar la build de producción localmente:

```bash
npm run preview
```

## 🛠️ Tecnologías

- **React 18** - Framework UI
- **Vite** - Build tool y dev server
- **React Router** - Enrutamiento
- **Leaflet + React Leaflet** - Mapas interactivos
- **Tailwind CSS** - Estilos
- **Lucide React** - Iconos
